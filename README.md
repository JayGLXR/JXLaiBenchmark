This repository contains a JPEX-XL (.JXL) file that displays the file's very own SHA-256 when decoded. The purpose of this file is to use as a benchmark for your AI-driven reverse engineering workflows, as well as for benchmarking the general intelligence of models. In an upcoming blog post, I will describe how it actually works in more detail.
